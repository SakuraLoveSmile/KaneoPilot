**一句话结论**：编排骨架已建成，黄金路径（To Do → 计划 → 执行 → 评审 → PR → 合并 → done）在沙盒里完整跑通过；但离验收标准（**连续 5 个任务到 PR 合并、0 次手动 resolve**）还差三块——

2. **UI 半边完全没动**：`macos/` 零改动，App 里没有任何引擎入口，生产里也没人启动引擎。
3. **上线与收尾未开始**：真实项目 shadow→live、推送合并、旧链清理。

**沿用的已确认选择**：范围＝重写编排层；规划/评审＝应用内直接调用 Codex/Claude（Plus 只管执行）；首页＝总览收件箱。

**三个与首版预期不同的事实**（决定了下面的排序）：
