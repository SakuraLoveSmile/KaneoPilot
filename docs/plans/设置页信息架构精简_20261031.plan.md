## 画板表达不了的规则

**编辑面板（规划 / 执行 / 评审，T2 做组件，T3 接线）**

- 结构：标题（「编辑 · 规划」）加一句范围；正文可滚动；脚栏固定：无法保存的原因单独一行并出现在「保存」左侧，其后「取消」「保存」。Esc 等于取消，Return 等于保存（可用时）。尺寸：最小宽 600pt、理想 640pt、最小高 360pt，正文随窗口高度滚动；900×600 下执行面板（约 494pt 加页眉脚栏）放不下，靠滚动，脚栏常驻。规格 §4.11 对浮层尺寸的要求（避免正文被压成只剩头部）同样适用。
- 草稿与保存：见 P1、P2。保存只提交当前面板的块，调用的核心命令不变：`set-planner-config`、`set-exec-config`、`set-review-config`；「保存 pi 不提交空桌面块，保存桌面不提交无关 CLI 草稿」（§4.9）沿用。保存期间禁用重复提交。
- 切换运行端只刷新只读的能力与候选，不覆盖草稿（§4.10）；Plus 候选刷新只填空草稿。
- 执行面板：权限模式首次必须显式选择，未选择时「保存」不可用，原因行写「保存不可用：请先选择权限模式」（§4.9）；「PI CLI 环境检查」按需出现（有未通过项时初始展开）；「派发与监控：确定性流程」降为脚注；「连接文件路径（随执行配置保存）」是全部设置里唯一可编辑的路径。
- 无障碍：面板标题是 heading；保存按钮沿用现有无障碍名（「保存规划配置」「保存 Review 配置」，执行的按同格式补「保存执行配置」）；「取消」「编辑…」带角色名；就绪状态是圆点加文字，不只靠颜色。

**Desktop 管理面板**：开关与按钮即时生效，只有「完成」；两个定时检查开关调 `model.setDesktopAutomation`，失败重读并显示错误（规格「Desktop 定时检查开关」）；「修改运行时间…」里的「保存运行时间」才写入（`model.setDesktopAutomationSchedule`，不开启已关闭的任务）；规格要求的两句说明（「关闭后不再定时唤醒；已开始的规划或 Review 会继续。恢复后可能立即处理到期任务。」与本地兼容适配说明）作为运行端页脚注常驻。

## 风险与未决

1. **画板是重画的草图**：系统 grouped `Form` 的行高、分隔线、分区间距与画板有近似误差，高度 ±15%；安装包 build 64 才是真实的「当前」。
2. **首屏余量小**：高级页 521pt 对首屏约 548pt，余量小于估算误差；「在首屏内」不是结论，要实测。
3. **没有 Swift 夹具覆盖设置页**（`macos/tests`、`macos/FakeCore`、`.github` 没有对 `SettingsView`、`ProjectMappingsView`、`SettingsSegment`、`MobileConnectionView` 的引用；`tests/` 里只有 `tests/rehearsal/fixtures/plus_plans_pending_real.json` 的历史计划正文提到 `SettingsView` 一词，不是代码引用）：云端绿灯只证明能编译，界面靠人工核对。
4. **`SettingsView.swift` 已 3516 行**：改成面板后长 `ViewBuilder` 的类型推断与编译耗时可能让云端编译失败；失败时按日志逐处修，不整体回退。
5. **逐阶段暂停失去界面入口**（D3 已选）：需要时只能走核心命令；`setPaused(stage:)` 保留（P6）。
6. **离线诊断没有手动入口**（P3）：想只跑离线检查（不探 Kaneo）已不可能；「在线诊断」在 Kaneo 不可达时的耗时与结果没有验证（客户端超时 120 秒，`AppViewModel.swift:354`），要实机看一次。首次诊断走静默路径后，失败只表现为摘要停在「尚未诊断」，没有错误提示，要靠用户点「在线诊断」才看到原因。
7. **探测未保存草稿路径的入口消失**（P7，S10 风险 14 的延伸）：改路径必须先在执行面板里保存，再到连接页探测。
8. **项目页部分成功**：命令之间不是事务，已成功的不回滚；两条命令之间若映射版本号被外部写入改变，下一条会报 `conflict`，按失败处理（停止、保留草稿，提示「放弃」后重来）。
9. **面板「打开时才读取」**：外部（如命令行）改了配置，要关面板重开才看到；页面进入时的加载仍保留。
10. **基线不稳**：本分支建在未合入 main 的 Mac UI 分支上，那个分支仍可能被别的会话更新（本任务 worktree 创建时，Mac UI 分支的工作树里有别人未跟踪的计划文件，没有触碰）。动工前核对 `claude/mac-ui-visual-typography-4180cf` 的 HEAD 是否仍是 `28dd98f`，变了先同步本分支并重核全部行号。
11. **画布文件名与页面**：`set-*` 是上一轮 4 块（在「既有画布」页），`ui03-set-*` 是本轮 5 块（在「第三轮」页）；S10 计划写的「共 23 块画板」现为 28 块，其中 23 块在「既有画布」页。
12. **从未编译**：全部 Swift 改动没有编译过（规则只在云端编译）。类型推断超时、遗漏的符号、`ViewBuilder` 子视图数量、`private` 嵌套类型的访问等问题只会出现在云端日志里；按日志逐处修，不整体回退。本机静态核对（执行记录 2026-11-01）不能代替编译。
13. **项目页草稿只在页面存活期内保留**：切到别的设置分组或离开设置页即丢弃（V5）；要保留须把草稿提到 `AppViewModel`，另议。
14. **保存栏只管当前选中的项目**（V5）：别的项目有草稿时只在列表行标「· 未保存」，要切过去才能保存。
15. **没有对照画布渲染过实现**：布局、间距、状态词的出入要装包后看；V1–V10 是已知的出入。
