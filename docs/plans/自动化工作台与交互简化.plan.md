# 自动化工作台与交互简化

状态：待体验。T1/T2/T3 已实现并完成本次适用验证，等待用户体验确认。

UI 简化冻结规格（2026-10-09）
T1 自动化总览：默认首页，侧栏按“工作台”(总览/任务/需要处理)、“记录”(执行会话/运行记录/归档/回收站)、“配置”(设置)分组。继承系统原生色、13/18/11pt 与8/12/16间距，不新增依赖/全局皮肤。总览按运行状态与暂停/恢复、规划→执行→评审→交付阶段计数、需要你处理、正在推进、最近完成顺序；真实 executor-status/overview/task 数据，缺失/离线不能称运行正常。立即检查显式解释会接收任务并推进。暂停说明不终止已启动任务。阶段暂停、调度关闭、项目未开启、诊断失败都可见并给设置入口。列表打开统一详情，确认执行进入已验证计划页，危险决议保留。
T2 任务与待处理：优先呈现核心异常、待确认计划/任务级暂停与失联；正常队列默认折叠，历史失败默认折叠且计数，保留原请求详情与清除确认。任务概览底栏一个安全推进主动作，低频动作进“更多操作”；发送不明不自动选风险决议，以重新校验为安全入口，危险操作仍二次确认。不新增核心状态写入。概览confirm_dispatch改为跳计划页，不直接执行；onSwitchTab不存在时禁用。允许动作与归档限制沿当前核心，不能自动重试/发布。
T3 设置与规划：设置默认项目与仓库，按三角色配置独立保存；保留后台运行/自动化常用项，通用诊断、路径、参数、MCP与迁移及领取验证默认折叠。阶段开关折叠但显示已暂停阶段摘要。项目默认显示仓库、自动处理开关、自动确认计划和成本/时长/修复预算；标签过滤、PR目标分支放高级选项，错误与预算摘要始终可见，折叠不丢草稿/改变策略。手动规划减少步骤：选择任务→核对材料并开始；运行环境信息默认折叠，最终用户确认保留。任何补充/文件/排除变更使准备结果过期并禁用提交，重新准备后才可提交新哈希。不绕过本地网络授权、仓库映射与核心校验。
分工：主 agent 唯一维护docs/ui-spec、docs/plans本次计划、RootView/AppViewModel/BoardView、新总览与Xcode注册，集成与原生核验。flow_worker独占PendingView与TaskDetailContentView；settings_worker独占SettingsView/ProjectMappingsView；planning_worker独占PlanningView及材料变更必要隔离夹具。三包接口仅复用现有model/core，可独立并行；不编辑其他文件，不派生。需共享模型新增请求回主控。
验收：独立bundle ID + FakeCore +临时support/db/凭据/状态，调度关闭，不访问真实模型/远端写；Release构建与现有Swift模型/规划相关夹具；主agent实测1180×760和900×600、浅/深色、主入口导航、详情菜单、发送不明确认、待处理折叠、设置草稿、规划编辑失效与新哈希。记录隔离证据，构建不代替UI。现有脏改动已通过source.zip+SHA256.json可恢复备份。不安装、不push、不发布。

实现与核验证据在本文件完成后追加。
