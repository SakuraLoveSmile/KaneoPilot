# 安卓界面按设计优化（施工计划）

## 概要

依据画布「优化后」板（`project/after-*.dc.html`，画布版本 1792648399-332b）逐屏核对 Android 实现，列出可见差异与改法。按 AGENTS.md「实现分歧先改规格再动工」，先改 `docs/mobile-console-contract.md` 的「视觉与状态」节，再改代码。未提交、未安装。

画布为设计目标，本计划不改画布。

## 核对方法

- 文字：提取 16 张优化后板的中文文本节点，与 `android/app/src/main/java/com/sakurasep/kaneopilot/*.kt` 及 `res/values*/` 字面比对。缺失项逐条判定：示例数据（不改）或真实缺口（列入下表）。
- 样式：读取板内 HTML 的字号、行高、高度、圆角、颜色与边距，对照 `Theme.kt` 与 `ConsoleUi.kt`。
- 示例文字（如「示例项目 A」「等待你回答 1 个规划问题（示例）」）只是样例数据，不作为代码文案。

## 不改的项

- 需要你列表的 failed 项显示为「需人工」：数据缺口（`attention` 条目不带异常严重度），沿 `安卓界面已知差异_20261022.plan.md` 第 6 项。需先改协议 §5.27.3，本次不做。
- 连接页保留设计板未列出的两段说明（「连接凭据由 Android Keystore 加密保存…」「若需撤销设备授权…」）。前者是契约内的安全说明，后者指明撤销入口，两段都保留。
- 画布不改。

## 契约改动（先于代码）

`docs/mobile-console-contract.md` 的「视觉与状态」节补充：

- 需要你条目（列表与总览）显示「打开任务 ›」，整卡可点击。
- 卡片顺序：徽标与项目名在前，标题居中，说明在后；最近进度与失败原因带前缀。
- 状态徽标：12sp；列表卡 24dp；总览计数与详情状态 28dp。
- 任务总览按看板、任务、请求分组。计数映射（取自 after-overview）：待规划、待办为中性、idle；进行中（看板与请求）、规划中、执行中为蓝、running；待评审为橙、review；需人工为橙、blocked；「阻塞 / 失败」为橙、blocked（计数汇总项，与单个状态「失败」的红色不同，需写明）；失败为红、failed；成功为绿、done；失联为红、blocked（与「执行端失联」一致，设计板未示）；已取消为中性、idle（设计板未示）；其余未知值为中性、unknown。
- 自动推进区的行布局与未连接状态。
- 对话框宽 320dp（板为 328dp，采用 320dp）；破坏性确认用 error 色。
- 详情页返回按钮在左。
- 执行轮次按钮、加载更多按钮、退出码颜色。

## 代码改动

- `StatusStyle.kt`：新增 `countStatusStyle(label)`，覆盖计数标签（待办、进行中、阻塞 / 失败、成功、失联、已取消），其余复用 `knownStatusStyle`。
- `ConsoleUi.kt`：
  - `StatusChip` 增加 `large` 参数，文字 labelMedium。
  - `TaskCard` 增加 `openHint` 参数，重排并加前缀。
  - `Section` 增加 `spacing` 参数；`LabelValue` 增加 `valueColor` 参数。
  - `TopBar`：详情页返回按钮左置，边距与缩进按板；详情页隐藏顶栏底线（页签下已有分隔线）。
  - `OverviewScreen`：自动推进行布局与未连接状态；任务总览分组徽标。
  - `AttentionList`：顶部标题；条目带入口提示。
  - `TaskOverview`：状态徽标。
  - `ExecutionScreen`：执行轮次按钮样式（当前轮次为 FilledTonal，显式 primaryContainer 底与 onPrimaryContainer 字；其余为 OutlinedButton，显式 onSurface 字，描边保持默认 outline）；当前会话状态色；加载更多按钮为 OutlinedButton。
  - `MessageCard`：退出码颜色。
  - `ConnectionScreen`：移除按钮文字色。
  - 所有 `AlertDialog`：宽 320dp；移除连接的确认按钮为 error 色。
- `StatusStyleTest.kt`：补 `countStatusStyle` 用例。

## 需确认的选择（非设计板原文）

- 已暂停的说明文案：「已暂停：运行中的会话继续执行。」，与已开启文案对称。未采用更长的「后续步骤不再自动推进」，以免新增说明。
- 退出码非 0 用错误色：设计板只示 0。
- 「失联」「已取消」的计数样式：见契约计数映射，设计板未示。
- 连接页两段说明保留（见「不改的项」）。
- 未连接时的自动推进区按设计板：16sp 说明、满宽禁用按钮，与已连接时的行布局不同。
