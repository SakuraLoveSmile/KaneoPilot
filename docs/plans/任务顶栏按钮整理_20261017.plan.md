# 任务页顶栏按钮整理

## 概要

「任务」页顶栏把全局控件（更新时间、暂停自动推进、刷新）和任务页控件（批量选择、添加任务、看板/列表、阶段筛选、搜索）混排在一起。多数按钮只有图标，或名称与实际行为不符，也没有分组，用户分不清哪个按钮影响什么。

本计划只定方案：不改代码、不改规格、不构建、不安装、不写库、不提交。按 AGENTS.md「实现分歧先改规格再动工」，实施前先修改 `docs/ui-spec.md` 中的工具栏描述；实施方式和四项设计选择待确认（见文末提问）。

状态：已实施代码与规格（2026-10-17，锚定 HEAD `7102a60`），已提交到分支 `claude/homepage-topbar-buttons-44a619`。Release 构建通过；**截图与布局未验证**，见「实施记录」。未安装、未写 live DB。

## 约束

- **部署目标 macOS 14.0**（`macos/KaneoPilot.xcodeproj/project.pbxproj`）：不使用 macOS 26 才有的工具栏 API（如 `ToolbarSpacer`），除非加 `#available` 并保留旧路径。
- **宽度**：1180×760 时详情区约 1000pt，900×600 且侧栏展开时约 720pt（侧栏 ideal 180pt，估算值）。八个都带文字的控件超出 720pt，会进入 `>>` 溢出菜单，比现在更混乱。方案必须合并或收起控件，不能只加文字。
- **测试耦合**：`tests/verify_batch_desktop.py:169` 按 `toolbar 1` 按钮的 description 包含「批量选择」查找入口，`:208` 注释同样依赖该名称。移动或改名都要同步此脚本。
- **其他需同步的文字**：`tests/ui-acceptance.md:17, :65, :114, :162`；`docs/ui-spec.md` §2（:18）、§4.1（:33, :56）、§4.7（:16, :215）、§4.13（:329–330）及 :454 的重复描述。
- **截图**：`scripts/preview_automation_ui.sh` 只构建并启动隔离预览（FakeCore、独立 bundle ID），本身不截图。截图需要屏幕录制权限，方式未验证，实施时先探测。

## 方案（推荐选项）

### 1. 分成两组，每个控件都有可见文字

**全局组**（作用于整个应用）：

- **自动推进**：按状态显示按钮文字。运行中为「暂停自动推进」；已暂停为橙色「已暂停 · 恢复自动推进」（只用系统语义色，颜色旁必须有文字）。提示改为「全局：暂停后不再自动领取新任务，已在执行的任务不受影响」。命令与语义不变。
- **刷新**：按钮显示文字「刷新」，并把上次刷新时间并入按钮（如「刷新 01:50」），完整时间放在提示中。⌘R 不变。
- **状态槽**：只在有横幅、命令进行中或核心缺失时显示，平时不占宽度。这一槽位的原有功能保留（规格 §2）。

**任务组**（只作用于当前看板或列表）：

- **规划待办…**（图标 `doc.text.magnifyingglass`）：替代「＋添加任务…」，打开同一规划面板。
- **看板 | 列表**：文字分段控件，标签与规格一致。
- **阶段筛选菜单**：标签显示当前值，如「阶段：全部」「阶段：待办」；有筛选时使用强调色。
- **更多**（`ellipsis` 菜单）：内含「批量选择…」；进入后显示「退出批量选择」，批量操作条的「完成」保持不变。
- **搜索**：保持系统 `.searchable`，提示文字不变。

### 2. 宽度估算（需截图核实）

暂停约 150pt、刷新约 110pt、规划待办约 110pt、分段约 120pt、筛选约 120pt、更多约 36pt，合计约 650pt。900×600 时搜索框折叠为图标，1180×760 时可展开。

把「批量选择」保留为文字按钮会再增加约 80pt，900×600 会溢出。这是推荐把它放进「更多」的主要理由。

### 3. 不做的事

- 不改变任何命令、排序、批量操作、确认流程或数据语义。
- 不改变 `set-paused` 的作用范围（仍是全局）。
- 不新增全局视觉 token，不加自定义胶囊或阴影；颜色只用系统语义色（规格 §3）。
