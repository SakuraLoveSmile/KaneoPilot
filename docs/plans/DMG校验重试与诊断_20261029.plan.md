## 0. Context

**问题**：Packages 的 DMG 步骤偶发失败。`scripts/build_dmg.sh` 在 `hdiutil verify` 报 `unable to recognize … (Resource temporarily unavailable)`，即 EAGAIN。失败发生在 verify 启动约 0.15 秒后，尚未进入内容校验；同一文件在 verify 之前执行的 `hdiutil imageinfo` 已经成功。

**结论（只读调查，2026-10-29）**：偶发、非确定性，不是打包代码引起的可复现问题。
- 同一提交 `9cf1fdd`：run `39985518274` 第 1 次尝试失败，第 2 次尝试（同一镜像、同一脚本）通过。
- 2026-10-22 之后，实际到达 verify 的 31 次独立执行中有 2 次失败（约 6%；95% Wilson 区间约 2%–21%）。通过的 29 次全部有 `checksum … is VALID`，且没有 `diskimages-help` 孤儿进程；两次失败都有孤儿进程。
- 排除项：两次失败中，`build_app.sh`、`hdiutil create`、`codesign` 与 `imageinfo` 均已通过，失败只出现在 verify。架构（lipo）与元数据步骤在失败之后才会运行，因此对失败的运行不作判断；编译失败与 fixtures 失败的运行不计入样本；`d6dedc7` 与 `98e4997` 之间 `scripts/`、`.github/` 无改动；运行器镜像相同（`macos-15`，`20260907.0337`）。
- **根因未定位**：失败瞬间持有镜像的进程没有被采集。孤儿 `diskimages-help` 是原因还是结果，目前无法判断。
- **已有的同类记录**：`docs/mobile-console-verification.md` 记录过本机 macOS 27 上的同一报错（资源暂时不可用）：一次 DMG 创建留下了只属于本产物的磁盘映射，核对归属并正常弹出后，镜像 CRC 校验通过。该记录也写明没有加入无限重试或对其他磁盘操作。云端 runner 上未证实是同一机制，但孤儿 `diskimages-help` 与之相符，`hdiutil info` 正是用来看这类映射的。

**本计划的目标**：让偶发的 EAGAIN 不再直接让构建失败，同时在每次运行里留下足够的信息，使下一次失败能定位持有者。

**边界**：verify 仍然是致命步骤；`publish` 门禁不变；不杀进程。

| 决定 | 默认 | 备选 | 理由 |
|---|---|---|---|
| 重试触发条件 | 仅 `Resource temporarily unavailable`（EAGAIN） | 任何失败都重试 | 其他失败多为真实损坏或签名问题，重试只会掩盖 |

| 耗尽后的副本兜底 | 纳入：复制为 `*.verify-copy.dmg`，两份 SHA-256 相同后，对副本执行 imageinfo 与 verify，结束后删除副本 | 不纳入：耗尽即失败 | 副本在另一路径，不受原文件上的持有者影响；字节相同是硬性前提 |
| 诊断输出 | 每次运行：create 与 codesign 之后各一次 diskimages 进程快照（列表可为空）。仅 EAGAIN 时：diskimages 进程列表（含 ppid）、`hdiutil info` 前 40 行、`lsof` 前 20 行 | 每次都采全量 | 快照很轻；较重的命令只在问题出现时运行 |
| 诊断超时 | `hdiutil info` 与 `lsof` 各 20 秒上限（perl alarm，macOS 无 timeout） | 不限时 | 诊断挂起会吃掉 45 分钟作业上限 |
| 分支基线 | `main` | 本 UI 分支 | 修复与 UI 工作无关；build_dmg.sh 在两者中相同 |
| `sync` | 不加 | create 后加 `sync` | 外部报告（CMake 讨论）建议过，但没有证据显示与本问题有关；与重试混在一起将无法归因 |

### 4.1 `scripts/dmg_retry.sh`（新增）

```bash
# Sourced by scripts/build_dmg.sh after the require_actions guard; not runnable on its own.
# Only the "Resource temporarily unavailable" (EAGAIN) signature is retried. Any other hdiutil
# failure returns its own exit code at once, so real corruption still fails the build.

DMG_RETRY_EXIT_EAGAIN=75

# macOS has no timeout(1); a hung diagnostic must not run into the 45-minute job limit.
diag_run() {
    perl -e 'alarm shift; exec @ARGV' 20 "$@"
}

# Printed on every run; never fails the build.
diskimages_ps() {
    echo "== diskimages processes: $1 ==" >&2
    ps -axo pid,ppid,etime,command | grep '[d]iskimages' >&2 || true
}

# Printed only after an EAGAIN.
dmg_diagnostics() {
    local dmg="$1" label="$2"
    {
        echo "== DMG diagnostics: $label =="
        ps -axo pid,ppid,etime,command | grep '[d]iskimages' || true
        diag_run hdiutil info 2>&1 | head -n 40 || true
        diag_run lsof "$dmg" 2>&1 | head -n 20 || true
    } >&2
}

# hdiutil_retry <subcommand> <image>: sleeps 5, 10, 15, 20 s between EAGAIN attempts.
hdiutil_retry() {
    local attempts="${DMG_RETRY_ATTEMPTS:-5}" delay="${DMG_RETRY_DELAY:-5}"
    local n out rc
    for ((n = 1; n <= attempts; n++)); do
        if out=$(hdiutil "$@" 2>&1); then
            if [ "$1" = verify ]; then
                printf '%s\n' "$out" >&2
            fi
            return 0
        else
            rc=$?
        fi
        printf '%s\n' "$out" >&2
        if [[ "$out" != *"Resource temporarily unavailable"* ]]; then
            return "$rc"
        fi
        echo "hdiutil $1: attempt $n of $attempts hit EAGAIN" >&2
        dmg_diagnostics "$2" "attempt $n of $attempts"
        if [ "$n" -lt "$attempts" ]; then
            sleep $((n * delay))
        fi
    done
    return "$DMG_RETRY_EXIT_EAGAIN"
}

verify_image() {
    local image="$1"
    hdiutil_retry imageinfo "$image" >/dev/null || return $?
    hdiutil_retry verify "$image"
}

# Last resort once the original keeps returning EAGAIN: verify a byte-identical copy at another path.
verify_copy_fallback() {
    local dmg="$1" copy="${1%.dmg}.verify-copy.dmg" want got rc
    want=$(shasum -a 256 "$dmg" | awk '{print $1}') || return 1
    if ! cp "$dmg" "$copy"; then
        rm -f "$copy"
        return 1
    fi
    if ! got=$(shasum -a 256 "$copy" | awk '{print $1}'); then
        rm -f "$copy"
        return 1
    fi
    if [ "$want" != "$got" ]; then
        echo "verify copy checksum mismatch; refusing to continue" >&2
        rm -f "$copy"
        return 1
    fi
    if verify_image "$copy"; then
        rc=0
    else
        rc=$?
    fi
    rm -f "$copy"
    return "$rc"
}

verify_dmg() {
    local dmg="$1" rc
    if verify_image "$dmg"; then
        return 0
    else
        rc=$?
    fi
    if [ "$rc" -ne "$DMG_RETRY_EXIT_EAGAIN" ]; then
        return "$rc"
    fi
    echo "original image still refused after retries; verifying a checksum-matched copy" >&2
    verify_copy_fallback "$dmg"
}
```

### 4.3 `scripts/tests/test_dmg_retry.py`（新增）

```python
"""DMG verify retry contract: EAGAIN-only retry, backoff, checksum-matched copy fallback. Stubs only."""
import os
from pathlib import Path
import subprocess
import tempfile
import unittest


REPO = Path(__file__).resolve().parents[2]
HELPER = REPO / "scripts" / "dmg_retry.sh"
WORKFLOW = REPO / ".github" / "workflows" / "packages.yml"
DRIVER = '#!/bin/bash\nset -euo pipefail\nsource "$1"\nshift\n"$@"\n'
STUBS = {
    "hdiutil": """#!/bin/sh
echo "$*" >> "$HDIUTIL_LOG"
if [ "$1" = info ]; then
    [ -n "$INFO_FAIL" ] && exit 1
    echo "image list stub"
    exit 0
fi
n=$(cat "$COUNT_FILE" 2>/dev/null || echo 0)
n=$((n + 1))
echo "$n" > "$COUNT_FILE"
case "$(echo "$OUTCOMES" | cut -d, -f"$n")" in
    ok)
        if [ "$1" = verify ]; then echo "hdiutil: verify: checksum of $2 is VALID" >&2; fi
        exit 0 ;;
    eagain)
        echo "hdiutil: $1 failed - Resource temporarily unavailable" >&2
        exit 1 ;;
    *)
        echo "hdiutil: $1 failed - corrupt" >&2
        exit 1 ;;
esac
""",
    "ps": """#!/bin/sh
[ -n "$PS_FAIL" ] && exit 1
[ -n "$PS_EMPTY" ] && exit 0
echo "  123     1 00:05 /usr/libexec/diskimages-helper"
""",
    "lsof": "#!/bin/sh\nexit 1\n",
    "sleep": '#!/bin/sh\necho "$1" >> "$SLEEP_LOG"\n',
    "shasum": """#!/bin/sh
for path; do :; done
echo "$path" >> "$SHASUM_LOG"
case "$path" in
    *.verify-copy.dmg)
        if [ -n "$SHASUM_MISMATCH" ]; then echo "0000  $path"; exit 0; fi ;;
esac
python3 -I -c 'import hashlib, sys; print(hashlib.sha256(open(sys.argv[1], "rb").read()).hexdigest(), sys.argv[1])' "$path"
""",
}


class DmgRetryTests(unittest.TestCase):
    def setUp(self):
        self.temp = tempfile.TemporaryDirectory()
        self.addCleanup(self.temp.cleanup)
        self.root = Path(self.temp.name)
        self.stub_dir = self.root / "bin"
        self.stub_dir.mkdir()
        for name, body in STUBS.items():
            command = self.stub_dir / name
            command.write_text(body, encoding="utf-8")
            command.chmod(0o755)
        self.driver = self.root / "driver.sh"
        self.driver.write_text(DRIVER, encoding="utf-8")
        self.out = self.root / "out"
        self.out.mkdir()
        self.dmg = self.out / "KaneoPilot.dmg"
        self.dmg.write_bytes(b"stable bytes for checksum matching\n")
        self.logs = {name: self.root / name for name in ("hdiutil.log", "shasum.log", "sleep.log", "count")}
        self.env = {key: value for key, value in os.environ.items() if not key.startswith("DMG_RETRY_")}
        self.env.update(
            PATH=f"{self.stub_dir}{os.pathsep}{os.environ.get('PATH', '')}",
            HDIUTIL_LOG=str(self.logs["hdiutil.log"]),
            SHASUM_LOG=str(self.logs["shasum.log"]),
            SLEEP_LOG=str(self.logs["sleep.log"]),
            COUNT_FILE=str(self.logs["count"]),
            INFO_FAIL="",
            PS_FAIL="",
            PS_EMPTY="",
            SHASUM_MISMATCH="",
        )

    def run_call(self, *call, outcomes="ok", flags=()):
        env = dict(self.env, OUTCOMES=outcomes, **{flag: "1" for flag in flags})
        return subprocess.run(["bash", str(self.driver), str(HELPER), *call], env=env,
                              capture_output=True, text=True, timeout=30)

    def lines(self, name):
        path = self.logs[name]
        return path.read_text(encoding="utf-8").splitlines() if path.exists() else []

    def hdiutil_calls(self):
        return [line for line in self.lines("hdiutil.log") if not line.startswith("info")]

    def sleeps(self):
        return [int(line) for line in self.lines("sleep.log")]

    def copy_exists(self):
        return (self.out / "KaneoPilot.verify-copy.dmg").exists()

    def test_eagain_then_success_retries_with_growing_backoff(self):
        result = self.run_call("verify_dmg", str(self.dmg), outcomes="ok,eagain,eagain,ok")
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.sleeps(), [5, 10])
        self.assertEqual(len(self.hdiutil_calls()), 4)
        self.assertIn("is VALID", result.stderr)
        self.assertIn("== DMG diagnostics: attempt 1 of 5 ==", result.stderr)

    def test_exhausted_retries_fall_back_to_a_checksum_matched_copy(self):
        result = self.run_call("verify_dmg", str(self.dmg),
                               outcomes=",".join(["ok"] + ["eagain"] * 5 + ["ok", "ok"]))
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.sleeps(), [5, 10, 15, 20])
        self.assertEqual(len(self.hdiutil_calls()), 8)
        self.assertEqual(sum("verify-copy" in call for call in self.hdiutil_calls()), 2)
        self.assertIn("verifying a checksum-matched copy", result.stderr)
        self.assertFalse(self.copy_exists())

    def test_other_failures_stop_at_once_with_hdiutil_exit_code(self):
        result = self.run_call("verify_dmg", str(self.dmg), outcomes="ok,invalid")
        self.assertEqual(result.returncode, 1, result.stderr)
        self.assertEqual(self.sleeps(), [])
        self.assertEqual(len(self.hdiutil_calls()), 2)
        self.assertNotIn("verify-copy", " ".join(self.hdiutil_calls()))

    def test_copy_checksum_mismatch_never_verifies_the_copy(self):
        result = self.run_call("verify_dmg", str(self.dmg),
                               outcomes=",".join(["ok"] + ["eagain"] * 5), flags=("SHASUM_MISMATCH",))
        self.assertEqual(result.returncode, 1, result.stderr)
        self.assertIn("checksum mismatch; refusing to continue", result.stderr)
        self.assertEqual(len(self.hdiutil_calls()), 6)
        self.assertEqual(len(self.lines("shasum.log")), 2)
        self.assertFalse(self.copy_exists())

    def test_imageinfo_eagain_is_retried_before_verify(self):
        result = self.run_call("verify_dmg", str(self.dmg), outcomes="eagain,ok,ok")
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.sleeps(), [5])
        self.assertEqual(len(self.hdiutil_calls()), 3)

    def test_failing_diagnostics_never_abort_the_retry(self):
        result = self.run_call("verify_dmg", str(self.dmg), outcomes="ok,eagain,ok",
                               flags=("PS_FAIL", "INFO_FAIL"))
        self.assertEqual(result.returncode, 0, result.stderr)
        self.assertEqual(self.sleeps(), [5])

    def test_process_snapshot_is_safe_when_empty_and_names_the_helper_when_present(self):
        empty = self.run_call("diskimages_ps", "after create", flags=("PS_EMPTY",))
        self.assertEqual(empty.returncode, 0, empty.stderr)
        self.assertIn("== diskimages processes: after create ==", empty.stderr)
        present = self.run_call("diskimages_ps", "after codesign")
        self.assertEqual(present.returncode, 0, present.stderr)
        self.assertIn("diskimages-helper", present.stderr)

    def test_workflow_syntax_checks_the_helper_with_the_build_scripts(self):
        checks = [line for line in WORKFLOW.read_text(encoding="utf-8").splitlines()
                  if "bash -n" in line and "scripts/build_dmg.sh" in line]
        self.assertEqual(len(checks), 1)
        self.assertIn("scripts/dmg_retry.sh", checks[0])


if __name__ == "__main__":
    unittest.main()
```

## 7. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 掩盖真实损坏 | 只对 EAGAIN 重试；副本必须与原件 SHA-256 相同；其他失败立即返回 hdiutil 原退出码 |
| 副本兜底被误报为原件通过 | §6 要求报告分开写；日志中有 `verifying a checksum-matched copy` 一行 |
| 诊断命令挂起 | `hdiutil info` 与 `lsof` 各 20 秒上限；`ps` 很快，未加限制 |
| 错误文本随系统或语言变化 | 错误文本不再匹配时不重试，失败快速返回，是安全侧 |
| 总耗时 | 单个重试序列的退避最多 50 秒；每次 EAGAIN 的诊断最多约 40 秒（`hdiutil info` 与 `lsof` 各 20 秒上限），每个序列最多 5 次，即约 200 秒。最坏情况（原件与副本各耗尽一个序列）约 8.5 分钟，远低于 45 分钟作业上限 |
| 回滚 | 改动在一个提交内；`git revert <commit>` 即可 |
