KaneoPilot 0.5.0

现在可以直接在调度台查看会话内容：任务详情「执行」页与独立执行会话页默认打开内容视图，按运行端记录持续更新，支持搜索、复制原文、展开工具记录和查看长消息全文。

- 自动跟随最新消息；上滚或暂停跟随后保留阅读位置，有新内容时可一键回到最新。
- 可切换到原有会话状态页，继续查看运行状态、模型、时间、Plus 状态核验和重新执行等操作；状态页暂停正文读取。
- 切换轮次与视图时隔离旧响应，读取失败保留已有内容并提供重试。

内容随运行端已导出的消息更新，默认每 2 秒检查，不是逐字流式输出。Codex Desktop 尚未导出原生对话，页面会提示到 Desktop 查看并提供会话 ID；不同运行端可见的工具细节与导出时机以实际记录为准。

本版无数据库结构变更，保留已有任务、会话记录和工作树。Android 同步发布 0.5.0 安装包，本次新增阅读界面在 macOS。
