# KaneoPilot v0.4.7

- 修复 Codex 执行 Flutter macOS / Android 构建时的工具目录权限和依赖准备问题。
- 新轮次使用私有 Pub / Gradle 写缓存，保留必要的 JDK / Android SDK 设置；离线准备锁定依赖和原生平台生成物。缓存不足时，在调用模型前显示具体原因。
- 修复空配置首次启动 Flutter 时被 metadata 网络探测中断的问题，公网限制继续生效。
- 失败详情保留摘要、失败命令与退出码，消除重复通用错误；超时或取消会清理依赖准备子进程，清理未确认时明确报错。
- 增加含原生插件的真实受限构建发布门禁，覆盖冷配置、macOS/APK、resume 和权限反例。

本版不改变数据库 schema。历史轮次保持原配置，不会自动重试；继续原任务需安装新版本后显式发起新轮次。云端夹具与发布通过不代表已安装或完成原业务任务、实体设备验收。
