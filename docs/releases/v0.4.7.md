# KaneoPilot v0.4.7

- 设置→运行端→执行新增 Codex“执行权限”，可选择“受限沙箱”或“无沙箱”。默认保持受限；保存后仅影响新轮次，不替换系统 Codex CLI。
- 无沙箱使用当前账户的文件与网络权限，可用于需要系统权限的原生构建。受限 macOS 的 workspace 类型查询、Gradle 9+ 的 SDK 插件根写入要求若不兼容，会在调用模型前说明原因并提示调整设置。
- 新轮次使用私有 Pub / Gradle 写缓存，保留必要的 JDK / Android SDK 设置；离线准备锁定依赖和原生平台生成物。缓存不足时，在调用模型前显示具体原因。
- 修复 Dart 分析器状态目录和 Android Gradle 缓存、插件生成目录及本地监听导致的受限验证失败；存在冲突的 JVM 参数时明确提示环境问题。
- 修复空配置首次启动 Flutter 时被 metadata 网络探测中断的问题；受限模式继续限制公网访问。
- 失败详情保留摘要、失败命令与退出码，消除重复通用错误；超时或取消会清理依赖准备子进程，清理未确认时明确报错。
- 后台执行状态读取失败时保留防休眠保护；较早发起、较晚返回的状态回执不再清除新的不确定状态与错误。
- 增加两种权限的真实平台发布门禁，覆盖冷配置、macOS/APK、resume 和受限模式的权限反例。两种模式均保留结构化报告、原生命令退出码和源码快照门禁。

本版不改变数据库 schema。历史轮次保持原配置，不会自动重试；继续原任务需安装新版本后显式发起新轮次。云端夹具与发布通过不代表已安装或完成原业务任务、实体设备验收。
