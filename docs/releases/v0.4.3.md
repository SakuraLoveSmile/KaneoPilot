# KaneoPilot v0.4.3

## 修复与改进

- **已结束任务可以整理到回收站**：当本轮执行已结束、正式评审通过且 PR 已合并时，不再仅因任务仍显示“评审中”而禁用回收。正在执行、回执不明、未结清发布和补验证仍会阻止移入，并在菜单中显示具体原因。沿用确认、取消和恢复流程。
- **首页更简洁**：移除引擎记录计数和实例列表，保留运行心跳、诊断与告警；没有诊断内容时隐藏展开入口。
- **普通任务补验证入口**：PR 合并后，若发布目标的完整源码尚未验证，可在任务详情准备补验证、查看目标与模型费用提示、确认启动并跟踪结果，通过后继续准备构建发布。准备和取消不会调用模型。
- **评审结果解析更严格**：损坏或拼错的 Plus Review 分段标记会明确报错，避免把正文里的示例 JSON 当成正式结论。
- **Android 界面与排版**：统一文字层级、状态词和徽标，改善问答与观测列表；需要处理的任务单独读取，保留任务页筛选结果。
- **历史工作树证据兼容**：工作树迁移后，核对仓库、任务分支及真实目录归属，允许读取原冻结路径的历史执行证据；新执行仍严格校验路径。新增显式工作树迁移命令，先预览与备份再确认，不会在升级时自动迁移。

## 升级说明

- 本版整合全部本地有效功能与验证记录，不自动更改真实任务状态，也不将项目外已发布的版本认领为新的发布批次。
- 本次不新增数据库 schema 版本。
- macOS 安装包支持 Apple Silicon（arm64）、macOS 14 及以上，内置 Python；采用 ad-hoc 签名，未公证。从旧 Universal 安装版本首次迁移仍需手动安装 arm64 包。Android 最低版本为 8.0，正式签名身份保持不变。
- Android 新布局的真机体验与真实模型调用仍待使用反馈。
