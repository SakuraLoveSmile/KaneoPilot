# KaneoPilot v0.4.5

## 修复与改进

- **修复 Flutter 验证的缓存写入权限**：Codex 新轮次会根据冻结验证命令，仅授权对应 Flutter SDK 的缓存目录，保持其他 SDK 文件和目录的写入限制。
- **失败轮次正确进入需要处理状态**：Codex 轮次失败或中止后，任务不再持续显示运行中；保留失败原因和已有成果，方便检查并安排下一步。
- **修正 Codex 完成报告提示**：按 Codex 的结构化 JSON 契约收集状态、检查退出码和待确认问题，避免误要求使用其他执行后端的报告工具。

## 升级说明

- 本次不新增数据库 schema 版本。历史失败轮次不会自动重跑，也不会追补缓存写入权限；继续原任务需显式启动新的执行轮次。
- macOS 安装包支持 Apple Silicon（arm64）、macOS 14 及以上，内置 Python，采用 ad-hoc 签名、未公证。Android 最低版本为 8.0，正式签名身份保持不变。

## 已知限制

- 继续保留 v0.4.4 已披露的异常终止边界：执行端在直接写入 job 文件期间被强制结束，可能留下不完整记录；本版未修改该历史路径。
- 本次验证包括隔离回归、受管进程夹具与云端检查。Android 真机、真实模型调用及安装后的原任务恢复尚未验证；发布完成与本机安装分别记录。
