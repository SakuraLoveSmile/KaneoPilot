# Privacy of historical evidence

Historical reports and build logs in this directory have been redacted for
public distribution. Developer home paths use `/Users/developer`, and hardware
identifiers use `REDACTED-DEVICE-ID`. These are illustrative placeholders.

The original execution dates and outcomes remain historical records, not checks
rerun by the privacy cleanup. Content hashes and absolute paths recorded before
redaction may no longer match these public copies. Re-run the documented checks
in an isolated environment to obtain current verification evidence.

Before committing new logs or screenshots, remove local paths, device IDs,
service credentials, personal signing identities, and private service URLs.
