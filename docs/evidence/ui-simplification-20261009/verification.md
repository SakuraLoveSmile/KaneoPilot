# UI 简化验证记录

状态：T1、T2、T3 均为待体验。本地实现和适用验证完成，尚未由用户确认验收。

## 用户能做成什么

- T1：默认打开自动化总览，看到运行/暂停/调度关闭、规划→执行→评审→交付、需要决定的事项与最近结果。点击阶段直达筛选后的任务列表；默认列表，保留看板。
- T2：需要处理优先呈现当前异常、待确认计划和任务暂停，正常队列及历史失败折叠。任务概览一个安全主动作；危险决议在更多操作并保留确认，确认执行先进入计划正文。PR结果常显，技术记录与预算按需展开，人工交付常显。
- T3：设置默认项目仓库，常用自动化配置与预算可见，诊断/高级信息折叠且不丢草稿。手动规划两步，材料编辑立即使旧版本失效，更新后才可开始，全部成功直接完成并回到总览。
